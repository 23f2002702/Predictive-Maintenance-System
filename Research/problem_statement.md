# Problem Statement

## Background

Manufacturing industries depend heavily on the continuous operation of machinery. Unexpected machine failures can result in production losses, increased maintenance expenses, delayed deliveries, and reduced operational efficiency.

Traditional maintenance approaches are generally categorized as:

1. Reactive Maintenance

   * Repair after failure occurs.

2. Preventive Maintenance

   * Maintenance performed at fixed intervals.

Both approaches have limitations. Reactive maintenance causes downtime, while preventive maintenance may replace components unnecessarily.

Predictive Maintenance offers an alternative strategy by using machine data to estimate failure risk before breakdown occurs.

---

## Research Problem

Can machine failure be predicted accurately using operational sensor data collected from manufacturing equipment?

---

## Research Objectives

1. Study machine operating conditions and failure patterns.
2. Identify variables associated with equipment failure.
3. Develop predictive machine learning models.
4. Compare model performance across multiple algorithms.
5. Estimate economic benefits resulting from predictive maintenance.

---

## Research Questions

RQ1:
Which operational variables have the strongest relationship with machine failure?

RQ2:
Can machine learning models accurately predict machine failures?

RQ3:
Which algorithm provides the best balance between accuracy and interpretability?

RQ4:
What economic benefits can be achieved through predictive maintenance implementation?
